# Прошивки ESP32-S3 + SimpleBGC / BaseCam

В каталоге `firmware` размещаются модернизированные прошивки проекта.

## Два варианта работы

**Direct:** одна ESP32-S3 читает три джойстика и передаёт Roll/Pitch/Yaw в SimpleBGC/BaseCam через UART / Serial API.

**BLE:** первая ESP32-S3 находится в пульте, читает три джойстика и передаёт значения по BLE. Вторая ESP32-S3 установлена на подвесе, принимает команды и передаёт их в BaseCam через UART.

## ESP32_BLE_Controller

Пульт BLE. GPIO джойстиков: GPIO6 / GPIO7 / GPIO15. Формат BLE-пакета: ASCII `x,y,z`. Период передачи: 20 мс.

## ESP32_BaseCam_Gimbal

Контроллер со стороны подвеса. UART к BaseCam: RX GPIO18, TX GPIO17, 115200 8N1. Этот же проект используется в Direct-режиме при `BLE_MODE_ENABLED 0`.

В модернизированной версии добавлены повторное подключение BLE, failsafe при потере связи, проверка входных BLE-пакетов, калибровка центра джойстиков, dead zone, лёгкая фильтрация, ограничение команд и вынесение основных параметров в `config.h`.

Поддерживаются режимы ANGLE и SPEED.

## Сборка

Целевая плата: ESP32-S3-DevKitC-1. Используется PlatformIO, `espressif32@6.7.0`, Arduino-ESP32 2.0.16. По переданному отчёту обе модернизированные прошивки успешно собираются.

Существующие уведомления об авторских правах и лицензиях в исходном коде должны сохраняться.
