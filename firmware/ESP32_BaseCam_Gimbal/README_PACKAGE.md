# ESP32 BaseCam Gimbal — modified firmware

The complete modified buildable project, including the bundled BaseCam `serialAPI` library and all supporting files, is provided in `../packages/ESP32_BaseCam_Gimbal_Modified.zip`.

The combined package containing both ESP32 projects and the project reports is available as `../packages/ESP32_SimpleBGC_Gimbal_Firmware_Modified.zip`.

The extracted modified `src/main.cpp` is also kept in this directory for convenient source review. Existing upstream license files and notices are preserved inside the supplied firmware package.
