# ESP32 Wireless CAN Gimbal Controller for SimpleBGC / BaseCam

ESP32-S3 based wired and BLE control system for a 3-axis SimpleBGC/BaseCam camera gimbal with CAN motor drivers. Includes hardware integration, wiring, pin maps, motor setup and bilingual EN/RU documentation.

> **Project status:** documentation and hardware integration are being prepared. Modified firmware will be published after review and testing.

## Open-source acknowledgment

This project builds on the open-source **ESP32 + BaseCam Bluetooth Gimbal Control** work by **Austin Allen / Elation Sports Technologies LLC**, distributed under the MIT License. The GEC Engineering version will include modified firmware, hardware-specific integration, expanded CAN motor documentation, wiring/pin maps, and English/Russian documentation.
