## GEC Engineering contribution

This repository is intended to document the GEC Engineering integration and subsequent development of the system, including hardware-specific wiring and pin mapping, CAN motor preparation, bilingual documentation, system integration, testing and future modified ESP32 firmware.

The repository does not currently contain the original ESP32 firmware source. Modified firmware will be added after engineering changes, review and testing.
