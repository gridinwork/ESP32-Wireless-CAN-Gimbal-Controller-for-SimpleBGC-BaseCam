# ESP32 Wireless CAN Gimbal Controller for SimpleBGC / BaseCam

Беспроводная и проводная система управления трёхосевым подвесом SimpleBGC/BaseCam на ESP32-S3 с CAN-драйверами двигателей. Документация описывает архитектуру системы, настройку контроллера, подготовку CAN-двигателей, подключение и режимы управления.

> **Статус проекта:** выполняется адаптация оборудования и документации. Исходный код прошивки намеренно пока не публикуется — он будет добавлен после модификации, проверки и тестирования.

[English version](README.md)

---

## 1. Назначение системы

ESP32-S3 используется как внешний контроллер трёхосевого подвеса. Он обрабатывает команды трёх независимых джойстиков для осей **Roll**, **Pitch** и **Yaw** и передаёт их контроллеру SimpleBGC/BaseCam через Serial API. BaseCam выполняет стабилизацию и управляет CAN-драйверами двигателей подвеса.

Предусмотрены два варианта:

1. **Прямое проводное управление** — один ESP32-S3 считывает три джойстика и непосредственно соединён с BaseCam по UART.
2. **Беспроводное BLE-управление** — первый ESP32-S3 находится в пульте и передаёт команды по Bluetooth Low Energy второму ESP32-S3, установленному на подвесе. Второй ESP32 передаёт команды BaseCam по UART.

Первоначальная концепция ESP32-программы основана на открытой MIT-разработке Austin Allen / Elation Sports Technologies. Подробности приведены в [ATTRIBUTION.md](ATTRIBUTION.md).

## 2. Основные компоненты

- контроллер SimpleBGC/BaseCam 32-bit;
- ESP32-S3 — одна плата для проводного варианта или две для BLE;
- три одноосевых джойстика;
- механика трёхосевого подвеса;
- три CAN-драйвера/двигателя;
- источник питания двигателей;
- USB для настройки через SimpleBGC GUI;
- UART между ESP32-S3 и BaseCam;
- CAN_H/CAN_L между BaseCam и драйверами двигателей.

Перед подачей питания обязательно проверяйте допустимые напряжения, полярность и распиновку именно вашей ревизии оборудования.

## 3. Первичная настройка SimpleBGC GUI до установки двигателей

### 3.1 Подключение GUI

Установите подходящую версию SimpleBGC32 GUI с официального сайта BaseCam Electronics. Подключите контроллер BaseCam к компьютеру по USB, выберите соответствующий COM-порт и нажмите **Connect**.

Убедитесь, что параметры платы корректно считываются.

Официальные загрузки: https://www.basecamelectronics.com/downloads/

### 3.2 Проверка и обновление прошивки

Откройте раздел **Upgrade / Firmware Upgrade** и проверьте совместимость версии прошивки контроллера и версии GUI с используемой аппаратной ревизией. При необходимости выполните обновление.

Не отключайте питание или USB во время записи прошивки.

### 3.3 Serial API

Откройте:

**RC Settings → Input Configuration**

В используемой конфигурации вход `RC_ROLL` назначается как **Serial port (Serial API, etc.)**, чтобы BaseCam принимал внешние команды от ESP32.

### 3.4 Выбор IMU

Откройте:

**Hardware → Main IMU Sensor**

Для платы с встроенным IMU его можно использовать как резервный датчик, если основной IMU не обнаружен. Для контроллеров без встроенного IMU параметр необходимо задавать согласно фактической конфигурации датчиков.

### 3.5 Скорость UART

В разделе последовательных интерфейсов установите:

- Main serial port speed: **115200 baud**;
- RC_SERIAL port speed: **115200 baud**.

ESP32 должен использовать ту же скорость UART.

### 3.6 Калибровка IMU

До окончательной установки двигателей выполните калибровку IMU. Размещайте контроллер/датчик в устойчивых известных положениях и последовательно калибруйте несколько ориентаций. После изменения параметров сохраните их в контроллер и проверьте после повторного подключения.

## 4. Подготовка CAN-двигателей и драйверов

### 4.1 CAN-шина

Основные соединения:

- `CAN_H` BaseCam → `CANH` всех драйверов;
- `CAN_L` BaseCam → `CANL` всех драйверов;
- плюс питания → VCC/силовой вход драйверов;
- минус питания → GND драйверов.

CAN_H и CAN_L желательно прокладывать витой парой. Для окончательной проводки необходимо учитывать требования к терминаторам CAN.

Каждому двигателю/драйверу должен быть назначен корректный CAN ID. До включения двигателей необходимо исключить конфликт адресов.

### 4.2 Обновление CAN_DRV

Для модулей BaseCam CAN_DRV подключите драйверы по CAN к основному контроллеру и подайте необходимое силовое питание. Одного USB недостаточно для питания CAN_DRV.

В SimpleBGC32 GUI:

1. Выключите двигатели кнопкой **MOTORS ON/OFF**.
2. Откройте **Upgrade → Connected modules**.
3. Нажмите **Refresh**.
4. Выберите нужный модуль и проверьте версии hardware/firmware/bootloader.
5. Выберите файл прошивки, предназначенный именно для этой ревизии драйвера.
6. Нажмите **Flash** и дождитесь окончания операции.
7. Перезапустите/переподключите контроллер.
8. Снова откройте Connected modules и убедитесь, что новая версия определяется корректно.

**Важно:** неправильная прошивка может вывести CAN-модуль из рабочего состояния.

Официальная информация BaseCam CAN Driver: https://www.basecamelectronics.com/can_driver/

### 4.3 Параметры двигателя

После обнаружения драйверов настройте параметры конкретного двигателя: число полюсов, тип и направление энкодера, а также электрические параметры двигателя, если они требуются используемым драйвером. В референсной системе использовались 28-полюсные двигатели, но это значение нельзя автоматически переносить на другой мотор.

Калибровку сопротивления/индуктивности и энкодера выполняйте только в соответствии с фактическим мотором и драйвером.

## 5. Прямое подключение — один ESP32-S3

Один ESP32-S3:

- считывает аналоговые сигналы джойстиков Roll/Pitch/Yaw;
- преобразует их в управляющие значения;
- передаёт команды BaseCam по UART через Serial API.

Референсная карта сигналов исходной реализации:

| Функция | ESP32-S3 | Подключение |
|---|---|---|
| Джойстик 1 | GPIO6 | SIG |
| Джойстик 2 | GPIO7 | SIG |
| Джойстик 3 | GPIO15 | SIG |
| UART RX | GPIO18 | BaseCam UART1_TX |
| UART TX | GPIO17 | BaseCam UART1_RX |
| Питание джойстиков | 3V3 | VCC всех джойстиков |
| Земля | GND | джойстики + BaseCam GND |

UART подключается перекрёстно: RX ESP32 → TX BaseCam, TX ESP32 → RX BaseCam.

Эта распиновка пока является описанием референсной реализации. Перед публикацией нашей модифицированной прошивки карта GPIO будет окончательно проверена и зафиксирована.

### Принцип работы

После запуска ESP32 устанавливает последовательную связь с BaseCam, непрерывно считывает три аналоговых канала, преобразует значения в команды Roll/Pitch/Yaw и передаёт их контроллеру BaseCam через Serial API.

Исходный код на данном этапе в репозитории не публикуется.

## 6. BLE-управление — два ESP32-S3

### ESP32 пульта

Первый ESP32-S3 считывает три джойстика и формирует значения Roll/Pitch/Yaw. Затем они передаются по **Bluetooth Low Energy** второму ESP32.

Пульт может иметь автономное питание от подходящего 5-вольтового USB-источника или аккумуляторной системы.

### ESP32 на подвесе

Второй ESP32-S3 принимает BLE-пакеты, разбирает/проверяет управляющие значения и передаёт команды в BaseCam по UART через Serial API.

CAN-часть между BaseCam и двигателями остаётся такой же, как в проводном варианте.

### Поток данных

`Джойстики → ESP32-S3 пульта → BLE → ESP32-S3 подвеса → UART / Serial API → BaseCam → CAN → драйверы двигателей`

В нашей будущей модифицированной прошивке будут отдельно определены BLE-сервис/характеристика, формат пакета, автоматическое восстановление соединения и failsafe.

## 7. Режимы Angle и Speed

### Angle — управление углом

Отклонение джойстика задаёт требуемое угловое положение соответствующей оси. BaseCam управляет двигателем так, чтобы привести Roll, Pitch или Yaw к заданному положению.

Этот режим удобен для позиционного управления камерой.

### Speed — управление скоростью

Отклонение джойстика задаёт скорость вращения. Чем сильнее отклонён джойстик от центра, тем выше требуемая скорость соответствующей оси. При возвращении джойстика в нейтральную область команда скорости становится близкой к нулю.

Этот режим удобен для плавного панорамирования и непрерывного движения камеры.

Выбранный режим должен согласовываться между настройками SimpleBGC и прошивкой ESP32. Dead-band/dead-zone помогает исключить самопроизвольное движение из-за небольшого шума ADC около центрального положения джойстика.

## 8. Статус прошивки

Исходный открытый проект демонстрирует проводное и BLE-управление, однако **его исходный код не публикуется здесь без изменений**.

Код нашего репозитория будет добавлен после модификации под оборудование GEC Engineering, проверки и тестирования. Планируется окончательная карта пинов, калибровка джойстиков, фильтрация/dead-zone, управление BLE-соединением, failsafe и более удобная конфигурация режимов.

---

## 9. Общие рекомендации

- Проверяйте распиновку каждой конкретной ревизии платы.
- Перед подключением аккумулятора дважды проверяйте полярность.
- Первую настройку выполняйте с выключенными двигателями.
- До запуска проверьте CAN_H/CAN_L и уникальность CAN ID.
- Используйте витую пару для CAN и правильное терминирование шины.
- Надёжно закрепляйте механику перед калибровкой двигателей.
- Первые тесты проводите с консервативными настройками мощности/тока.
- Проверьте центр и dead-zone каждого джойстика.
- Для BLE-версии обязательно используйте failsafe при потере связи.
- Перед экспериментами сохраняйте резервную копию рабочей конфигурации BaseCam.
